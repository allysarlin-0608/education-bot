# 測試版部署步驟

正式版和測試版用**同一份程式碼**（同一個 GitHub repo、同一個 `main` 分支），
只差在 Streamlit 的 **Secrets**：測試版接另一個 Supabase 專案、用另一組密碼。
這樣測試者上的課、打的勾、建的書，只會存在測試用的資料庫，不會混進 Allysa 的真實紀錄。

| | 正式版 | 測試版 |
| --- | --- | --- |
| 網址 | education-bot-b7nleshsrcvwjaflgwe3tx.streamlit.app | 自己取，例如 allysa-coach-test.streamlit.app |
| Supabase 專案 | 現在用的那個 | **新開一個**，例如 `education-bot-test` |
| `APP_PASSWORD` | Allysa 用的密碼 | **另一組**，只給測試者 |
| 程式碼 | `main` 分支 | 同一個 `main` 分支 |

## 1. 開一個測試用的 Supabase 專案

1. 到 https://supabase.com ，按 **New project**。
   - Project name：`education-bot-test`
   - Region：跟正式版一樣（Tokyo 或 Singapore）
   - 方案：Free
2. 建好後，左邊 **SQL Editor** → **New query**，貼上 repo 裡 `supabase/schema.sql` 的全部內容，按 **Run**。
   看到 `Success. No rows returned` 就好（這份一次建好所有資料表和權限，不用再跑其他 .sql）。
3. 到 **Project Settings → Data API** 複製 **API URL**，
   到 **Project Settings → API Keys** 複製 **secret key**（`sb_secret_` 開頭）。
   **注意是測試專案的，不要複製成正式版的。**

## 2. 在 Streamlit 部署第二個 app

1. 到 https://share.streamlit.io ，按 **Create app** → **Deploy a public app from GitHub**。
2. 填：
   - Repository：`allysarlin-0608/education-bot`
   - Branch：`main`
   - Main file path：`streamlit_app.py`
   - App URL：取一個看得出是測試版的名字，例如 `allysa-coach-test`
3. 按 **Advanced settings**，在 **Secrets** 貼上（引號裡換成測試版的值）：

   ```toml
   GROQ_API_KEY = "gsk_..."
   SUPABASE_URL = "https://測試專案.supabase.co"
   SUPABASE_KEY = "sb_secret_測試專案的key"
   APP_PASSWORD = "測試版專用的密碼（不要跟正式版一樣）"
   ```

4. 按 **Deploy**，等一兩分鐘。

## 3. 確認兩邊真的分開了

1. 打開測試版，輸入測試版密碼，上一堂課並打勾。
2. 到**測試專案**的 Supabase → **Table Editor → learning_entries**，應該看得到那一筆。
3. 到**正式專案**的 Supabase 看同一個表，**不應該**多出那一筆。
4. 用正式版的密碼登入測試版，應該會被拒絕（兩邊密碼不同）。

## 4. 要知道的事

- **Groq 額度是共用的**：兩邊用同一把 `GROQ_API_KEY` 的話，會一起算 Groq 每分鐘 8,000 tokens 的上限，
  測試者大量測試時，正式版可能會比較常出現「教練現在有點忙」。想完全分開，就用另一個 Groq 帳號的 key
  （同一個 Groq 組織底下的不同 key 還是共用額度）。
- **程式更新會同時到兩邊**：兩個 app 都接 `main`，推送新程式碼時兩邊一起更新。
- **只給測試者測試版的網址和密碼**，正式版的網址和密碼只給 Allysa。
- **「匯入學習紀錄」只在測試版測**，匯入會整份取代資料庫裡的紀錄。
- **測試完要清空測試資料**時，在**測試專案**（再三確認不是正式專案）的 SQL Editor 執行：

  ```sql
  -- 只能在測試專案執行！會刪掉測試資料庫裡的全部紀錄和書。
  truncate public.learning_entries;
  truncate public.reading_books;
  ```
