## 10. 限制（這次做不到的）

- 只有 Chromium。沒有 Safari（iPad / iPhone）和 Firefox 可以跑；iPad/iPhone 用 Chromium 模擬尺寸、觸控和 UA，
  鍵盤開啟時用「變矮的視窗」模擬。**真正的 Safari 請妳用 iPad/iPhone 看一下。**
- 沒有真的 AI：模型的回覆用假的（可以控制失敗、延遲、注入內容）。真實模型的內容品質（全英文、Note 不亂稱讚）
  是用提示詞規則 + 後處理 + 測試確認，但沒辦法對真的模型大量抽查。
- 沒有連到真的測試 Supabase，也量不到 Streamlit Cloud 的冷啟動時間。
- 猴子測試約 27% 的隨機點擊點到被擋住或正在移動的元素（3 秒逾時後換下一步），這是隨機點擊的正常現象。
